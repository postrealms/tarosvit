# Таросвіт

PWA для тлумачення карт таро по фото. Ти наводиш камеру на карту в рамці, за бажанням пишеш питання, а застосунок називає карту, її положення (пряме чи перевернуте) і дає тлумачення. Є історія тлумачень і акаунт.

Побудовано так само, як «Калорія»: статичні файли + серверні функції Vercel + Supabase, без збірки й без залежностей.

- Тлумачення робить Claude API через серверну функцію `api/analyze.js`. Ключ зберігається лише на сервері.
- Без акаунта історія лежить на телефоні. З акаунтом вона зберігається в Supabase і доступна на інших пристроях. Те, що до входу лежало на телефоні, переноситься в акаунт під час першого входу.
- Працює на Android (Chrome, Samsung Internet) та iPhone (Safari), встановлюється на головний екран.

## Структура

```
index.html            розмітка: заставка, видошукач з рамкою, тлумачення, історія, акаунт
privacy.html          політика конфіденційності (чернетка, впиши контактний email)
app.css               стилі (одна темна тема)
app.js                логіка: камера, тлумачення, історія, акаунт
sw.js                 service worker (оболонка застосунку працює офлайн)
manifest.webmanifest  маніфест PWA
icons/                іконки
api/analyze.js        серверна функція Vercel → Claude API (перевірка входу, денний ліміт)
api/account.js        видалення акаунта разом з усіма даними
api/_sb.js            спільні функції для роботи з Supabase
supabase/schema.sql   таблиці, правила доступу, денний ліміт
vercel.json           заголовки
```

## Розгортання

### 1. Ключ Claude API
Можна взяти той самий ключ, що й для «Калорії», але окремий зручніший: видно витрати саме цього застосунку.
1. https://console.anthropic.com → **API Keys** → «Create Key», назва `tarosvit`. Скопіюй ключ, він показується лише один раз.
2. У **Limits** перевір місячний ліміт витрат.

### 2. Код на GitHub
Створи на github.com порожній репозиторій `tarosvit` (без README). Далі або завантаж туди вміст цієї папки через «uploading an existing file», або скажи Claude, і він викладе код сам.

### 3. Vercel
1. https://vercel.com → «Add New…» → «Project» → поруч із `tarosvit` натисни «Import».
2. Framework Preset: **Other**. Нічого більше не змінюй.
3. **Environment Variables**:
   - `ANTHROPIC_API_KEY` — ключ з кроку 1
   - `ACCESS_CODE` — слово для тестувальників (дуже раджу: без нього будь-хто з посиланням витрачатиме твій баланс)
4. «Deploy». Приблизно за хвилину буде адреса на кшталт `tarosvit-xxxx.vercel.app`.

На цьому етапі застосунок уже працює: без входу, історія на телефоні.

### 4. Акаунти (Supabase)
Вхід без пароля: email і код з листа.

Раджу окремий проєкт Supabase, а не той, що в «Калорії». Таблиці названо так, що вони не конфліктують, але в спільному проєкті користувачі теж спільні: «Видалити акаунт» у Таросвіті видалить і акаунт цієї людини в «Калорії».

1. https://supabase.com → «New project», назва `tarosvit`.
2. SQL Editor → встав `supabase/schema.sql` → Run.
3. Authentication → Emails → Templates: у шаблонах **Confirm signup** і **Magic Link** має бути `{{ .Token }}` (код), а не посилання.
4. Authentication → URL Configuration → Site URL: адреса застосунку з Vercel.
5. Vercel → Environment Variables: `SUPABASE_URL`, `SUPABASE_SECRET_KEY` (secret key, `sb_secret_…`), за бажанням `DAILY_LIMIT` (за замовчуванням 15). Потім Redeploy.
6. Project URL і publishable key (`sb_publishable_…`) впиши на початку `app.js` в об'єкт `SB`. Вони публічні, дані захищають правила доступу в базі.

Поки `SUPABASE_URL` і `SUPABASE_SECRET_KEY` не задані, застосунок працює без входу. Коли задані, тлумачення доступні лише після входу, і діє денний ліміт.

Вбудована пошта Supabase надсилає лише кілька листів на годину. Для справжніх користувачів підключи свій SMTP (Authentication → Emails → SMTP Settings), як у «Калорії».

### 5. Встановлення на телефон
- **Android:** відкрий адресу в Chrome або Samsung Internet → меню → «Встановити застосунок» / «Додати на головний екран».
- **iPhone:** відкрий адресу в **Safari** → «Поділитися» → «На початковий екран».
- Під час першого запуску введи код доступу й дозволь доступ до камери. Якщо камеру не дозволено, кнопка зйомки відкриває штатну камеру телефона.

## Налаштування сервера
- `CLAUDE_MODEL` (необов'язково) — модель для тлумачення, за замовчуванням `claude-sonnet-5-5`.
- `DAILY_LIMIT` (необов'язково) — тлумачень на користувача на день, за замовчуванням 15. Фото без карти таро спробу не з'їдає.
- Ліміт запитів на одну IP-адресу: 12 на хвилину (у `api/analyze.js`, константа `RATE`).

## Оновлення версії
Коли змінюєш файли застосунку, підніми номер у трьох місцях: `VERSION` в `app.js`, `VERSION` в `sw.js`, `version` у `package.json`.
